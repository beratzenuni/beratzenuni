**AI-Assisted Terraform Generation** - _Master thesis · South East European University_

An empirical study of how well large language models generate Terraform infrastructure code, comparing Hetzner Cloud against AWS on the same projects.

- Status: In progress 🚧
- Terraform · Hetzner Cloud · AWS · Python
- Measures correctness, cost, security, and right-sizing against expert-written baselines
- Tests whether runtime telemetry from deployed systems can produce cheaper configurations that still meet their service-level objectives
- Early finding: generated Hetzner code can pass terraform plan yet fail once deployed - one sample never configured the private network interface, so the load balancer returned 503
